# Python Bill Splitter

A simple Python program that calculates the total cost of a meal, adds a 25% tip and divides the final bill equally among four people.

## Features

* Stores individual meal costs
* Calculates the total bill
* Calculates a 25% tip
* Adds the tip to the total
* Splits the bill among four people
* Rounds the final amount to two decimal places

## Technologies Used

* Python

## How It Works

The program adds the costs of appetizers, main courses, desserts and drinks. It then calculates a 25% tip and adds it to the total bill. Finally, the program divides the total by the number of friends and rounds the result to two decimal places.

## Example

```text
Total bill so far: 198.83
Tip amount: 49.7075
Total with tip: 248.5375
Bill per person: 62.134375
Each person pays: 62.13
```
